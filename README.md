# Museoedu

Museoedu website research, content context, design-system documentation, and the first implementation of the redesigned landing page.

## Project structure

- `museo-landing/` — responsive static landing page
- `page-context/` — structured content inventory for the existing Museoedu website
- `dashdigital-design-system.md` — design-system study used as visual inspiration
- `scripts/` — page-context and stylesheet maintenance utilities

## Preview the landing page

Serve `museo-landing/dist/` with any static HTTP server, then open `index.html`.

The landing page uses semantic HTML, responsive CSS, accessible navigation and accordions, reduced-motion support, and lightweight vanilla JavaScript.
